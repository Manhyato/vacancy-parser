# Отчёт по заданию 10: ## Асинхронное получение и объединение данных с использованием CompletableFuture

## Цель: 
**Продемонстрировать работу с многопоточностью с использованием CompletableFuture:**

## Реализация:

Создание пула потоков — Executors.newFixedThreadPool() с именованными потоками.

Асинхронные вызовы:

fetchPrice() и fetchName() — эмуляция внешних API.

fetchRate() — имитация курсов валют.

Комбинирование результатов — через thenCombine.

Обработка ошибок — через exceptionally, логирование неудачных запросов.

Агрегация — сбор частичных результатов, даже при ошибках.

Сравнение скорости — асинхронная версия выполняется значительно быстрее синхронной.

## Результаты теста:

Потоки: async-fetcher-* работают параллельно.

Ошибки для P3 и P5 корректно обработаны, приложение не упало.

Все успешные результаты собраны в единый список.

## Выводы:

Асинхронная реализация позволяет сократить время выполнения до ~1.8 секунд.

Ошибки обрабатываются локально, результат остаётся частично валидным.

Собственный Executor обеспечивает управляемость и читаемые логи.

##  Использованные технологии

Java 17

Spring Boot 3.5.7

**Потоковые механизмы:** synchronized, ReentrantLock, Condition

**Инструменты диагностики:** jstack, jps
