# Отчёт по заданию 8: ## Асинхронные HTTP-запросы с ThreadPoolExecutor

## Цель: реализовать систему, которая отправляет несколько HTTP-запросов параллельно с помощью `ThreadPoolExecutor`.

## Реализация:
- Создан список из 15+ публичных API.
- Использован `ExecutorService` с пулом потоков фиксированного размера.
- Для каждого запроса измеряется время отклика и статус-код.
- Результаты собираются и анализируются по завершении всех задач.

## Результаты теста:
Среднее время ответа: ~1090 мс.  
Большинство запросов вернули код 200, что подтверждает корректность параллельной работы.  
Некоторые тестовые API (httpstat.us) намеренно возвращали ошибки 404/500 для проверки устойчивости программы.

## Вывод:
Асинхронная обработка с `ThreadPoolExecutor` позволяет существенно сократить общее время выполнения за счёт параллельной отправки запросов. Приложение корректно собирает результаты и устойчиво к ошибкам соединения.

##  Использованные технологии

Java 17

Spring Boot 3.5.7

**Потоковые механизмы:** synchronized, ReentrantLock, Condition

**Инструменты диагностики:** jstack, jps
