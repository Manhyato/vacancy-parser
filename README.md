# Отчёт по заданию 8: ## Асинхронные HTTP-запросы с ThreadPoolExecutor

## Цель: 
**Продемонстрировать работу с многопоточностью в Java:**

отмена задач через Future;

параллельное выполнение через invokeAll;

периодические задачи через ScheduledExecutorService;

асинхронный сбор данных в PeriodicDataAggregator.

## Реализация:

**1. Future и отмена задачи**

Создан ExecutorService, запущена долгая задача.
Через 3 секунды вызван future.cancel(true) → задача корректно прервана.

**2. invokeAll()**

Создан список из 5 задач, выполняющихся 1–3 сек.
Метод invokeAll() запускает их одновременно и возвращает результаты.

**3. ScheduledExecutorService**

Периодическая задача (проверка системы) выполняется каждые 2 секунды,
через 8 секунд планировщик завершает работу.

**4. PeriodicDataAggregator**

Сервис каждые 5 сек. асинхронно обновляет данные по сущностям (USD, EUR, BTC и др.).
Обрабатываются как успешные результаты, так и ошибки.

## Результаты теста:

**Future и отмена задачи:**
Задача успешно запущена и корректно прервана через cancel(true) — поток завершил выполнение без ошибок.
**ivokeAll():**
Все 5 задач завершились корректно, время выполнения соответствует ожидаемому диапазону (1–3 сек).
**ScheduledExecutorService:**
Периодическая задача “Проверка статуса системы” выполнялась каждые 2 секунды и завершилась по расписанию.
**PeriodicDataAggregator:**
Асинхронные запросы к «сущностям» (USD, EUR, BTC, ETH, JPY) выполнялись каждые 5 секунд.
В логах видно: часть обновлений проходит успешно, часть выбрасывает исключения — это ожидаемое поведение, имитирующее реальные сетевые ошибки.

## Выводы:

Вывод: Future позволяет управлять и отменять выполнение потоков.
Вывод: ScheduledExecutorService подходит для фоновых сервисов и мониторинга.
Вывод: PeriodicDataAggregator демонстрация асинхронного сбора данных и устойчивости к сбоям.
Вывод: invokeAll удобно для пакетного параллельного выполнения задач.
