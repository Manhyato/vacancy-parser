# Отчёт по заданию 14: ##  Введение в проект Loom (Virtual Threads).

## Цель работы/

Сравнить производительность выполнения 10 000 параллельных задач с использованием:
виртуальных потоков (имитация лёгких асинхронных задач);
платформенных потоков (Thread).

## Реализация:

**Создание задач:**
Каждая задача выводит имя потока и имитирует неблокирующую I/O операцию (Thread.sleep()).

**Запуск виртуальных потоков:**
Используется фабрика Executors.newVirtualThreadPerTaskExecutor()
(или аналог при отсутствии StructuredTaskScope в Java 17).

**Запуск платформенных потоков:**
Для сравнения создаются обычные потоки через new Thread(...).start().

**Измерение времени:**
С помощью System.currentTimeMillis() измерено время выполнения обеих стратегий.

## Результаты теста:

**Пример логов работы:**
Thread-9980 выполняет Platform-9980
Thread-9990 выполняет Platform-9990
Платформенные потоки завершили выполнение за: 956 мс

=== Результаты ===
Псевдо-виртуальные потоки: 201 мс
Платформенные потоки: 956 мс

## Выводы:

Виртуальные потоки выполняют большое количество коротких задач значительно быстрее.
Они создаются и завершаются почти без накладных расходов на переключение контекста.
Платформенные потоки тяжелее, что делает их менее эффективными при массовом запуске.
Виртуальные потоки подходят для масштабных асинхронных систем и имитации I/O-нагрузок.
