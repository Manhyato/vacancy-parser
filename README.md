# Отчёт по Vacancy Parser — Spring Boot MVC приложение

## Описание

**Vacancy Parser — это учебное многоисточниковое приложение для парсинга вакансий с сайтов HH.ru, Habr Career и SuperJob**

**Проект демонстрирует:**
работу с многопоточностью (ExecutorService + @Async),
использование H2 Database для хранения данных,
применение планировщика задач (@Scheduled),
извлечение и обработку данных с разных источников,
применение Parallel Stream API для сортировки и фильтрации,
простую веб-интерфейсную часть (HTML + CSS) для удобной работы с результатами.

## Запуск проекта

**Установите зависимости**

**Убедитесь, что установлены:**
Java 17+
Maven 3.5.7

**Соберите проект**
mvn clean package

**Запустите Spring Boot приложение**
mvn spring-boot:run

или через IntelliJ IDEA / VS Code — просто запустить VacancyParserApplication.java.

**Перейдите в браузер**
http://localhost:8080/

Откроется главная страница с вакансиями.

## Результаты и выводы

**Проект соответствует всем требованиям задания:**

MVC-архитектура
Многопоточность (ExecutorService + @Async)
Планировщик задач (@Scheduled)
Встроенная база данных H2
Потокобезопасность и Parallel Stream API
Реализованы API эндпоинты

**В итоге создано полностью рабочее учебное приложение, которое:**

собирает вакансии с разных источников,
сохраняет их в базу данных,
позволяет управлять результатами через API и веб-интерфейс.

##  Использованные технологии

**Язык**	Java 17
**Фреймворк**	Spring Boot 3.5.7
**Web**	Spring MVC, Thymeleaf (HTML шаблон)
**Асинхронность**	@Async, ThreadPoolTaskExecutor
**Планировщик**	@Scheduled
**База данных**	H2 (in-memory / embedded)
**Парсинг**	Jsoup, HH API
**Многопоточность**	CompletableFuture + кастомный пул потоков
**Фронтенд**	HTML + CSS
