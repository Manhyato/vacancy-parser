# Отчёт по заданию 12: ## использование потокобезопасных коллекции из пакета java.util.concurrent для создания многопоточных приложений.
## Цель: 
**Продемонстрировать работу с многопоточностью с использованием CompletableFuture:**

## Реализация:

**Созданы основные компоненты системы:**

Event — модель события.
EventProducer — потоки, генерирующие события.
EventConsumer — поток, обрабатывающий события.
EventCache — кэш, реализованный на ConcurrentHashMap.
EventSystemDemo — демонстрация взаимодействия потоков через BlockingQueue.

И**спользованы потокобезопасные структуры:**

LinkedBlockingQueue — обмен событиями между продюсерами и консумером.
ConcurrentHashMap — хранение обработанных событий без блокировок.
ExecutorService — управление пулом потоков.

**Добавлено логирование и корректное завершение потоков.**
События генерируются, обрабатываются и добавляются в кэш параллельно.
