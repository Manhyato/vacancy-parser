# Отчёт по заданию 10: ## Асинхронное получение и объединение данных с использованием CompletableFuture

## Цель: 
**Продемонстрировать работу с многопоточностью с использованием CompletableFuture:**

## Реализация:

Создан класс AggregationCounterTask, наследующий RecursiveTask<Integer>.

Реализован метод compute(), выполняющий:

разделение диапазона на подзадачи,

рекурсивное выполнение (fork() / join()),

объединение частичных результатов.

В ForkJoinDemo реализован запуск ForkJoinPool и вывод итогового количества элементов.

Поддерживается параллельная обработка батчей с логированием текущего потока.

## Результаты теста:

Пример логов работы:
[ForkJoinPool-1-worker-1] Обработан диапазон 6?8 ? 2
[ForkJoinPool-1-worker-4] Обработан диапазон 0?2 ? 2
[ForkJoinPool-1-worker-3] Обработан диапазон 4?6 ? 1
[ForkJoinPool-1-worker-2] Обработан диапазон 2?4 ? 2
Итоговое количество успешных элементов: 7
=== Демонстрация ForkJoin завершена ===

## Выводы:

Реализован рекурсивный подсчёт через ForkJoin
Задача разбивается на батчи и выполняется параллельно
Итоговый результат корректно объединяется
Логирование позволяет проследить распределение задач между потоками
